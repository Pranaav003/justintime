Is this a website or a VS Code extension?+

JustInTime is a VS Code extension. This website’s playground is a fixed, local illustration of the experience. It doesn’t connect to your editor, execute code, or use an AI provider.

Which AI providers can I use?+

The extension supports Claude and compatible providers. You configure your own provider in the extension; this website asks for no credentials. See the repository’s requirements for setup details.

Will Explain mode change my files?+

No. Explain is read-only and walks through the relevant code without diffs. Solve proposes changes and lets you decide whether to apply or skip each step.

How does recovery work?+

Revert All is an explicit workspace-wide recovery action available after a restart. It is scoped to the first workspace folder. Review the repository documentation before using it in your project.

How do I get started?+

Get the MIT-licensed source from GitHub and follow the development setup. The guide covers running the extension in a VS Code Extension Development Host with F5.
